# 🌱 Plantochi

**Tamagotchi for Plants** — приложение для iOS с мягкой геймификацией ухода за реальными растениями через обучение, визуал и наблюдение.

## 📱 О проекте

Plantochi — это живой обучающий проект, который растёт вместе с пользователем. Цель приложения не просто "не забывать поливать", а:

- 🎯 Научиться замечать признаки состояния растений
- 💡 Понимать, почему нужно делать те или иные действия
- ✨ Видеть последствия и награды заботы
- 🌿 Постепенно вырастить осознанность и уверенность в уходе за растениями

Игра не наказывает, не давит, не оптимизирует. Она сопровождает и отражает.

## ✨ Основные возможности

### 🏠 Экран "Дом"
- Изометрическая сетка с визуализацией всех растений
- Тотем дома, отражающий общее состояние экосистемы
- "Дыхательные" анимации для каждого растения
- Визуальные индикаторы состояния (цвет, свечение)

### 🌿 Экран "Растение"
- **Режим "Вид"**: крупный визуал растения, настроение, анимации
- **Режим "Детали"**: визуальные индикаторы влажности и комфорта, история действий
- Выполнение действий с возможностью добавления заметок и фото

### ➕ Добавление растений
- Выбор типа растения из предустановленного списка
- Добавление фото из галереи или камеры
- Персонализация имени

### 📋 Действия
- Полив 💧
- Удобрение 🌱
- Поворот 🔄
- Очистка 🧹
- Пересадка 🪴
- Обрезка ✂️

Каждое действие влияет на скрытые параметры растения (влажность, стресс) и отражается в визуальном состоянии.

## 🏗️ Архитектура

### Технологии
- **SwiftUI** — современный UI фреймворк
- **SwiftData** — локальное хранение данных
- **PhotosPicker** — работа с изображениями
- **iOS 17+** — минимальная версия

### Структура проекта

```
Plantochi/
├── Models/
│   └── DataModels.swift          # SwiftData модели
├── ViewModels/
│   ├── HomeViewModel.swift       # Логика экрана "Дом"
│   └── PlantViewModel.swift      # Логика экрана "Растение"
├── Views/
│   ├── Home/
│   │   ├── HomeView.swift        # Главный экран
│   │   ├── PlantCardView.swift   # Карточка растения
│   │   └── TotemView.swift       # Тотем дома
│   ├── Plant/
│   │   ├── PlantDetailView.swift # Детали растения
│   │   ├── AddPlantView.swift    # Добавление растения
│   │   └── ActionSheetView.swift # Выполнение действий
│   └── Stubs/                    # Заглушки для будущих экранов
├── Theme/
│   └── AppTheme.swift            # Цвета, типографика, стили
└── Components/
    └── BreathingAnimation.swift  # Компонент анимации
```

### Модели данных

- **PlantInstance** — основная модель растения с состоянием здоровья
- **ActionLog** — история выполненных действий
- **HomeEntity** — состояние дома и тотема
- **PlantType** — типы растений (суккулент, фикус, монстера и др.)
- **PlantAction** — типы действий

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/maximchkv/Plantochi.git
```

2. Откройте проект в Xcode:
```bash
cd Plantochi
open Plantochi.xcodeproj
```

3. Выберите симулятор или устройство (iOS 17+)

4. Запустите проект (⌘R)
