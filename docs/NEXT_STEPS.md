## 💡 Советы для следующего агента

1. **Начни с экрана "Сегодня"** — это ключевой экран для ежедневного использования
2. **Система рисков** должна быть мягкой — без давления, только визуальные индикаторы
3. **Используй существующие паттерны** — смотри на `KnowledgeViewModel` для примера работы с данными
4. **Визуал важнее цифр** — индикаторы должны быть визуальными (полоски, цвета), не процентами
5. **Тестируй с seed data** — в `KnowledgeViewModel.seedInitialData()` есть примеры создания данных
